# Code of Conduct

The django-push-notifications project adopts the [Django Commons Code of Conduct](https://github.com/django-commons/membership/blob/main/CODE_OF_CONDUCT.md).

By participating in this project, you agree to abide by this Code of Conduct.
Please report violations to the Django Commons Code of Conduct team at
[django-commons-coc@googlegroups.com](mailto:django-commons-coc@googlegroups.com),
following the reporting guidance in the Code of Conduct.
